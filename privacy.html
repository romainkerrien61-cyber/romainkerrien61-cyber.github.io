Politique de confidentialité

Cette notice concerne ELAP Archive Drive, outil à usage personnel géré par Romain Kerrien, et ses tests de qualification.

Données et finalité

L'application utilise l'adresse du compte Google pour vérifier le compte autorisé. Elle traite les fichiers autorisés, leurs noms, tailles, identifiants, dates et empreintes SHA-256 pour les copier, vérifier leur intégrité et éviter les doublons. Les fichiers peuvent contenir des données personnelles.

Le seul accès Google demandé est drive.file, limité aux fichiers créés ou explicitement sélectionnés ou ouverts avec l'application.

Stockage et services utilisés

Les copies et leurs preuves sont conservées dans Google Drive avec des accès privés. Les exécutions automatisées utilisent un dépôt privé GitHub et GitHub Actions ; les credentials OAuth sont conservés dans les secrets Actions. Les scripts de qualification ne publient pas ces valeurs dans leurs rapports. Les archives Drive n'ont pas de suppression automatique ; leur conservation reste sous le contrôle du titulaire.

Ce site public contient uniquement des informations sur l'application. Il ne reçoit ni credentials, ni archives. Il n'intègre ni formulaire de connexion, ni publicité, ni outil de suivi ajouté par l'application. GitHub, qui héberge le site, enregistre notamment les adresses IP des visiteurs pour la sécurité, selon sa politique de confidentialité.

Usage et contrôle

Les données obtenues via les API Google sont utilisées pour les fonctions d'archivage décrites ici, conformément à la Google API Services User Data Policy, y compris ses exigences Limited Use applicables. L'application ne vend pas ces données et ne les utilise pas pour la publicité ou l'entraînement de modèles d'IA.

Le titulaire peut révoquer l'autorisation dans son compte Google. La révocation arrête l'accès autorisé ; elle ne supprime pas les copies déjà conservées. Questions : romainkerrien61@gmail.com.
